# 内置词库来源与覆盖

- 文件：`seed.ts`
- 规模：224 个词条，16 个真实任务场景，每个场景 14 个词。
- 来源：本项目原创英汉释义、英文例句和中文例句。没有复制第三方词典、商业背词产品或考试大纲。
- 许可：本项目贡献者将本文件中的原创词库文本以 **CC0-1.0** 贡献，可独立导出和复用。软件代码许可与词库文本许可可以分别管理。
- 覆盖：通用英语与服务器部署、网络、数据存储、GPU 云计算和 AI 工作流的交叉词汇。这不是完整 CET-4 词库，也没有逐词核对某一考试年份的官方范围；“通用”不等同于“官方四级词条”。
- 发音：另见 `pronunciations.ts` 与 `PRONUNCIATION_SOURCES.md`，218/224 词条有可追溯美式 IPA，6 词待补；第三方音标不属于上文原创 CC0 范围。没有词典真人音频；不要把浏览器合成语音说成词典真人录音。

## 数据结构

`seedWords` 使用可移植 `Word` 类型；每条含稳定 `id`、`term`、`meaning`、`example`、`exampleZh`、`tags`、`sceneIds`、`source`。`seedScenes` 的 `wordIds` 只引用已存在词条。

场景顺序是一条由简到繁的真实任务链：选实例 → SSH → 防火墙 → 发布应用 → 域名/TLS → 存储备份 → 性能监控 → 故障排查 → 容器 → GPU 选型 → 计费 → 数据准备 → 训练 → API 推理 → 数据库 → 英文交接。

未来引入第三方词库时，应保留原始来源、版本与许可，不将仓库代码的许可证自动等同于全部上游数据版权已审计。
